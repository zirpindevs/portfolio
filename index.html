01 · IOT / AUTOMATIZACIÓN Proyecto hardware

Smart Aquarium Automation

Conjunto de scripts Python y utilidades de shell para automatizar y monitorizar un acuario físico mediante Raspberry Pi. El código se organiza por áreas de control y periféricos.

Qué incluye

  • Control GPIO de dispositivos del acuario, como iluminación, calentador y ventilación.
  • Evaluación y registro de temperatura y estado.
  • Persistencia MySQL, tareas programadas y utilidades para LCD, botones y sensores.
Python Raspberry Pi GPIO MySQL / PyMySQL Linux / cron
02 · API REST / IOT API Flask

Acuarium Python API

API REST en Flask para consultar información y ejecutar operaciones de control de un acuario conectado a Raspberry Pi.

Qué incluye

  • Autenticación JWT para operaciones protegidas.
  • Consulta de tiempo desde el último sifonado.
  • Endpoints POST para encender y apagar iluminación y calentador.
  • Acceso a MySQL mediante PyMySQL y operación acotada de mantenimiento de un servicio Java.
Python 3.11+ Flask Flask-JWT-Extended PyMySQL MySQL pytest
03 · BACKEND / JAVA Spring Boot

Smart Aquarium Backend

Backend Java para una aplicación de gestión de acuario. La estructura separa controladores, servicios, repositorios, modelos de persistencia y componentes de seguridad.

Dominios identificados

  • Gestión de peces, artículos e inventario.
  • Usuarios y autenticación.
  • Datos meteorológicos, impresora y operaciones de limpieza ecológica.
  • Persistencia relacional con Spring Data JPA y MySQL.
Java 8 Spring Boot 2.4.3 Spring Web Spring Security JPA MySQL Maven JWT
04 · API REST / SERVICIOS Flask + SQLAlchemy

Estepona Taxi API

Backend API para una aplicación relacionada con reservas de taxi y cálculo de precios. La aplicación está organizada en configuración, modelos, rutas y servicios.

Qué incluye

  • Aplicación Flask y capa de modelos con SQLAlchemy.

05 · IA / ORIENTACIÓN LABORAL Demo desplegada

FP Match · Inteligencia artificial y orientación profesional

FP Match es una aplicación web diseñada para conectar la formación profesional con las oportunidades del mercado laboral. Su objetivo es ayudar a los usuarios a explorar itinerarios formativos, descubrir especialidades y encontrar información relevante para orientar su futuro profesional.

La plataforma incorpora un asistente conversacional basado en inteligencia artificial que permite interactuar mediante lenguaje natural. La interfaz, desarrollada con Angular, se comunica con un backend en Node.js y Express, que gestiona las peticiones y la integración con la API de OpenAI.

Características principales

  • Asistente conversacional con integración de OpenAI.
  • Exploración de ciclos formativos y especialidades profesionales.
  • Consulta de información y datos relacionados con la inserción laboral.
  • Arquitectura frontend y backend desacoplada mediante API REST.
  • Control de frecuencia de peticiones en el servidor.

Stack tecnológico

Angular 19 TypeScript Node.js Express OpenAI API RxJS REST API

06 · FRONTEND / DASHBOARD Angular 11

Acuarium Frontend

Aplicación frontend Angular para visualizar y gestionar distintas áreas del ecosistema Acuarium. La estructura incluye páginas, componentes, modelos, guards y pruebas unitarias.

Secciones visibles en el código

07 · JAVA / API REST Servicio backend

Servicio de Información de Proveedores

Aplicación backend Java con Spring Boot que expone un endpoint REST para consultar proveedores asociados a clientes y devolver los resultados en JSON.

Qué incluye

  • Endpoint GET /api/proveedores.
  • Separación en controlador, servicio, modelo y repositorio.
  • Persistencia con Spring Data JPA y MySQL.
  • Documentación interactiva con OpenAPI/Swagger y pruebas unitarias con JUnit 5.
Java 17 Spring Boot 3.4.2 Spring Web Spring Data JPA MySQL JUnit 5 OpenAPI Maven

Test Andalucía API
