Sobre este portafolio

Aprendizaje aplicado y proyectos reales

Estos proyectos reflejan trabajo práctico en distintas capas del desarrollo: desde scripts y automatización hasta APIs, servicios backend e interfaces web.

El objetivo de este espacio es presentar de forma clara el tipo de problemas abordados, las tecnologías utilizadas y la evolución del trabajo.

Áreas de trabajo

  • Desarrollo con Python
  • APIs y servicios backend
  • Desarrollo web frontend
  • Java y Spring Boot
  • IoT y automatización
  • Pruebas y documentación de APIs
